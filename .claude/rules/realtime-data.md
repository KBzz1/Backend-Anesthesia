# 实时数据规则

- STOMP/WebSocket 路径、broker 前缀和主题约定属于协议面，不要随意修改。
- 不要为了"清理代码"改写稳定的实时链路。
- `StompDataConsumer`、`DataController`、`WebSocketConfig` 都属于高风险模块。
- 修改实时数据链路前，先明确接入、持久化、推送三个环节分别受什么影响。
- 不要随意改变 `StompDataConsumer` 的消息解析结构和入库逻辑。
- 不要基于猜测修改 `backend-relay` 相关行为。
- 如果改动涉及实时波形、低频聚合、生理参数推送，必须明确指出影响的是哪一段链路。
- 修改后要说明如何验证：数据是否进入后端、是否写入数据库、是否到达订阅者。
