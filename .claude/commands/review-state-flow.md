# 任务审查模板：患者状态流转 / 状态机改动

请把当前任务当作"患者状态流转 / 状态机改动"来审查，并严格按下面步骤执行：

1. 先识别本次任务涉及哪些状态与转换点
2. 检查是否会影响：
   - 等待区
   - 排队
   - 叫号
   - 准备区
   - 手术中
   - 恢复区
   - 出院
   - ARS 汇总
3. 检查是否涉及 `PatientStatusServiceImpl`
4. 默认不要修改状态码语义和状态转换条件
5. 如果必须修改，先说明：
   - 受影响状态
   - 受影响链路
   - 可能的连锁影响
6. 优先提出局部修复方案，不要先提流程重构
7. 最后总结：
   - 这是局部 bug 修复还是状态机语义变更
   - 风险等级
   - 推荐改动边界
