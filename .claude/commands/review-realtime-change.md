# 任务审查模板：实时数据 / 设备链路改动

请把当前任务当作"实时数据 / 设备链路改动"来审查，并严格按下面步骤执行：

1. 先识别是否涉及以下模块：
   - `StompDataConsumer`
   - `DataController`
   - `WebSocketConfig`
   - `DeviceBindingServiceImpl`
   - `backend-relay`
2. 追踪这次改动影响的是哪一段链路：
   - 数据接入
   - 数据持久化
   - 数据推送
   - 设备绑定
   - relay 转发
3. 默认不要修改既有 topic、路径、broker 前缀、消息结构
4. 如果信息不全，明确标记"待确认"，不要脑补协议与机制
5. 优先提出最小安全改法
6. 修改建议里必须包含验证思路：
   - 数据是否进后端
   - 是否落库
   - 是否推送给订阅者
7. 最后总结：
   - 受影响链路
   - 风险等级
   - 推荐改动范围
