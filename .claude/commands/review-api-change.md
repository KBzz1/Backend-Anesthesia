# 任务审查模板：API 接口变动

请把当前任务当作"API 接口变动"来审查，并严格按下面步骤执行：

1. 先识别本次任务是否涉及 `接口文档.md` 中定义的契约
2. 检查是否影响 Controller 层、请求参数、响应字段
3. 检查是否涉及接口路径、字段名、字段类型、字段语义的变更
4. 引用 `.claude/rules/api-contract.md` 规则进行合规判断
5. 如果实现与接口文档不一致，先记录差异点，再说明影响，不要直接改任一方
6. 如果接口变更无法避免，必须先列出：
   - 受影响接口及路径
   - 受影响请求/响应字段
   - 前端影响范围
7. 优先提出局部修复方案，不要以"后端实现更合理"为由改变契约
8. 最后总结：
   - 变更类型（契约内局部修改 / 契约外新增 / 契约不一致记录）
   - 向后兼容影响
   - 风险等级
   - 推荐改动边界
