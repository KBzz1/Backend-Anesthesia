# 任务审查模板：接口契约敏感型改动

请把当前任务当作"接口契约敏感型后端改动"来审查，并严格按下面步骤执行：

1. 先阅读 `接口文档.md` 中对应接口
2. 对照实现，检查是否涉及：
   - 路径变化
   - 请求字段变化
   - 响应字段变化
   - 字段类型变化
   - 字段语义变化
3. 默认保持向后兼容
4. 如果确实需要变更契约，不要直接改代码，先列出：
   - 受影响接口
   - 受影响字段
   - 对前端的影响
   - 为什么无法兼容
5. 优先提出"最小兼容改法"
6. 最后总结：
   - 本次改动是否触及契约
   - 风险等级
   - 推荐修改范围
